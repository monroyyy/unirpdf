## Que es PDFusion?

**PDFusion** es una herramienta web minimalista y elegante para combinar multiples archivos PDF en un solo documento. Todo el procesamiento ocurre en tu dispositivo — ningun archivo se envia a internet.

Hecho por **SystemMp** — 2026.

## Caracteristicas

- **Drag & Drop** — Arrastra tus PDFs directamente a la pagina
- **Reordenamiento visual** — Arrastra las tarjetas para cambiar el orden de los documentos
- **Informacion de archivos** — Muestra nombre, tamano y numero de paginas de cada PDF
- **Barra de progreso** — Feedback visual durante la fusion
- **Descarga automatica** — El PDF resultante se descarga al instante
- **100% local** — Ninguno de tus archivos sale de tu dispositivo
- **Sin instalacion** — Abre el archivo `index.html` y listo
- **Easter egg** — Prueba el Konami Code 🎮

## Uso

1. Clona este repositorio o descarga los archivos
2. Abre `index.html` en tu navegador
3. Selecciona o arrastra tus archivos PDF
4. Reordenalos si es necesario
5. Haz clic en **"Fusionar PDFs"** y descarga el resultado
